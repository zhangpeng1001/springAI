# 05 - 函数调用（Function Calling）

> 对应代码：`FunctionCallController.java`，工具：`WeatherTools.java`、`CalculatorTools.java`

## 功能说明

函数调用（Function Calling / Tool Calling）是 Spring AI 的核心功能之一，
它允许大模型**调用你定义的 Java 方法**，从而获取实时数据或执行操作。

这让 AI 从"只能说"变成"能做事"：
- 查询实时数据（天气、股票、数据库）
- 执行操作（发邮件、调 API、写文件）
- 精确计算（AI 的数学计算可能不准确）

## 工作流程

```
用户："北京天气怎么样？"
   ↓
大模型识别需要调用工具 → 返回工具调用请求：getCurrentWeather("北京")
   ↓
Spring AI 自动执行 Java 方法 → 调用 WeatherTools.getCurrentWeather("北京")
   ↓
方法返回："北京今天的天气：晴天，温度25°C"
   ↓
Spring AI 将结果发回大模型
   ↓
大模型整合后回答："北京今天天气晴朗，气温25°C，适合外出活动。"
```

## 定义工具

使用 `@Tool` 注解标注方法即可声明工具：

```java
@Component
public class WeatherTools {

    @Tool(description = "查询指定城市的实时天气情况")  // 描述工具用途
    public String getCurrentWeather(
            @ToolParam(description = "城市名称") String city  // 描述参数
    ) {
        // 实际逻辑：可以调用真实天气 API
        return "北京今天的天气：晴天，温度25°C";
    }
}
```

### 关键注解

| 注解 | 作用 | 位置 |
|------|------|------|
| `@Tool` | 声明方法为工具，description 描述用途 | 方法上 |
| `@ToolParam` | 描述参数含义，帮助 AI 正确传参 | 参数上 |

**重要**：`description` 非常关键，AI 根据它判断是否需要调用该工具。

## 接口说明

### 1. 天气查询 `GET /function/weather`

```
GET /function/weather?question=北京和上海今天天气怎么样？
```

代码核心：
```java
String response = chatClient.prompt()
    .user(question)
    .tools(weatherTools)  // 注册工具
    .call()
    .content();
```

AI 会自主决定：
- 调用 `getCurrentWeather("北京")` 获取北京天气
- 调用 `getCurrentWeather("上海")` 获取上海天气
- 整合两个结果给出最终回答

### 2. 计算器 `GET /function/calc`

```
GET /function/calc?question=请计算 1234 乘以 5678 等于多少
```

AI 调用 `multiply(1234, 5678)` 精确计算。

### 3. 多工具组合 `GET /function/multi`

同时注册多个工具，AI 自主选择。

```
GET /function/multi?question=北京天气怎么样？另外帮我算一下 100除以7
```

```java
chatClient.prompt()
    .user(question)
    .tools(weatherTools, calculatorTools)  // 注册多个工具
    .call()
    .content();
```

AI 会分别调用天气工具和计算器工具。

### 4. 天气预报 `GET /function/forecast`

```
GET /function/forecast?question=广州未来3天天气如何
```

## 本项目的工具一览

### WeatherTools（天气工具）
| 方法 | 说明 | 参数 |
|------|------|------|
| `getCurrentWeather` | 查询实时天气 | city |
| `getWeatherForecast` | 查询天气预报 | city, days |

### CalculatorTools（计算器工具）
| 方法 | 说明 | 参数 |
|------|------|------|
| `add` | 加法 | a, b |
| `subtract` | 减法 | a, b |
| `multiply` | 乘法 | a, b |
| `divide` | 除法 | a, b |

## AI 如何决定调用工具

AI 根据 `@Tool` 的 `description` 和用户的提问来判断：

```
用户："北京天气如何？"
AI 内部推理：
  - getCurrentWeather 的描述是"查询指定城市的实时天气"
  - 用户问的是天气，匹配！
  - 参数 city = "北京"
  → 调用 getCurrentWeather("北京")
```

如果用户问的是不相关的问题，AI 不会调用工具，直接回答。

## 应用场景

| 场景 | 工具示例 |
|------|---------|
| 实时数据查询 | 天气、股票、汇率、数据库查询 |
| 外部 API 调用 | 发送邮件、创建工单、查询物流 |
| 精确计算 | 数学运算、单位换算 |
| 文件操作 | 读写文件、生成报表 |
| 系统集成 | 调用内部系统 API |

## 注意事项

1. `description` 要写清楚，AI 靠它判断是否调用
2. 工具方法需要是 `public` 的
3. 工具类需要注册为 Spring Bean（`@Component`）
4. AI 可能错误传参，方法内要做好参数校验
5. 工具调用会增加请求轮次（先调用工具再生成回答），响应会稍慢

## 学习要点

1. `@Tool` 注解声明工具，`@ToolParam` 描述参数
2. `.tools()` 方法注册工具给 ChatClient
3. AI 自主决定是否调用工具和传什么参数
4. 可以同时注册多个工具
5. description 是 AI 判断的依据，要写准确
