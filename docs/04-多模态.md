# 04 - 多模态（Multimodal）

> 对应代码：`MultimodalController.java`

## 功能说明

多模态（Multimodal）是指模型能够同时处理多种类型的输入，如文本、图片、音频等。
Spring AI 支持在用户消息中嵌入图片，让大模型"看图说话"。

本模块演示：
1. 通过图片 URL 让 AI 分析网络图片
2. 通过本地文件让 AI 分析本地图片
3. 使用 ImageModel 生成图片（文生图）

## 前置条件

- 需要使用**支持视觉的模型**，如 GPT-4o、GPT-4o-mini
- 文生图需要支持 DALL-E 的 API

## 接口说明

### 1. 分析网络图片 `GET /multimodal/url`

通过图片 URL 让 AI 分析图片内容。

```
GET /multimodal/url?imageUrl=https://example.com/image.png&question=描述这张图片
```

代码核心：
```java
// 构建图片 Media 对象
Media imageMedia = Media.builder()
    .mimeType(MimeTypeUtils.IMAGE_PNG)
    .data(URI.create(imageUrl))  // 图片 URL
    .build();

// 构建包含文本和图片的用户消息
UserMessage userMessage = new UserMessage(question, imageMedia);

// 调用模型（需要使用支持视觉的模型）
chatClient.prompt()
    .options(OpenAiChatOptions.builder().model("gpt-4o").build())
    .messages(userMessage)
    .call()
    .content();
```

### 2. 分析本地图片 `GET /multimodal/local`

从 classpath 加载本地图片进行分析。

```
GET /multimodal/local?question=这张图里有什么
```

使用前需要在 `src/main/resources/images/` 目录下放置一张测试图片（如 `sample.png`）。

代码核心：
```java
Resource imageResource = new ClassPathResource("images/sample.png");

Media imageMedia = Media.builder()
    .mimeType(MimeTypeUtils.IMAGE_PNG)
    .data(imageResource)  // 本地文件资源
    .build();
```

### 3. 文生图 `GET /multimodal/generate`

使用 ImageModel 根据文字描述生成图片。

```
GET /multimodal/generate?prompt=一只在月亮上的猫
```

代码核心：
```java
ImagePrompt imagePrompt = new ImagePrompt(prompt);
ImageResponse response = imageModel.call(imagePrompt);
String imageUrl = response.getResult().getOutput().getUrl();
```

## 核心概念

### Media 对象

`Media` 是 Spring AI 中表示非文本媒体的抽象：

```java
Media.builder()
    .mimeType(MimeTypeUtils.IMAGE_PNG)  // MIME 类型
    .data(URI/Resource/byte[])           // 数据源（URL/文件/字节数组）
    .build();
```

支持的数据源类型：
- `URI` - 网络图片 URL
- `Resource` - 本地文件资源
- `byte[]` - 原始字节数据

### UserMessage

`UserMessage` 可以同时包含文本和多个 Media：

```java
UserMessage message = new UserMessage("描述这张图", image1, image2);
```

### ImageModel

`ImageModel` 是 Spring AI 的图像生成接口：
- `imageModel.call(ImagePrompt)` - 同步生成
- 返回 `ImageResponse`，包含生成图片的 URL

## 支持的 MIME 类型

| 类型 | MIME Type |
|------|-----------|
| PNG 图片 | `image/png` |
| JPEG 图片 | `image/jpeg` |
| GIF 图片 | `image/gif` |
| WebP 图片 | `image/webp` |

## 应用场景

| 场景 | 说明 |
|------|------|
| 图片描述 | 自动生成图片 alt 文本、商品描述 |
| 图片问答 | 基于图片内容回答问题 |
| OCR 识别 | 从图片中提取文字信息 |
| 内容审核 | 判断图片是否包含违规内容 |
| 辅助功能 | 为视障用户描述图片内容 |

## 注意事项

1. **模型要求**：多模态需要使用支持视觉的模型（如 gpt-4o），默认配置的 gpt-4o-mini 可能不支持
2. **图片大小**：过大的图片会消耗更多 token，建议压缩后发送
3. **URL 可达性**：通过 URL 发送图片时，模型服务器需要能访问该 URL
4. **隐私安全**：敏感图片建议通过本地文件方式发送，避免上传到公网

## 学习要点

1. `Media` 对象封装图片，`UserMessage` 可同时包含文本和多个 Media
2. 图片可来自 URL、本地文件或字节数组
3. 需要使用支持视觉的模型
4. `ImageModel` 用于文生图
