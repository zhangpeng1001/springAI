# 03 - 结构化输出（Structured Output）

> 对应代码：`StructuredOutputController.java`，模型：`ActorFilms.java`

## 功能说明

结构化输出是 Spring AI 非常强大的功能：它可以将大模型返回的自由文本
**自动转换为 Java 对象**（POJO）、List、Map 等结构化数据。

无需手动解析 JSON，Spring AI 全部帮你搞定。

## 工作原理

```
用户提问 → Spring AI 生成 JSON Schema → 约束模型输出 → 自动反序列化为 Java 对象
                ↓                            ↓
          根据 Java 类生成            模型返回符合 Schema 的 JSON
```

1. Spring AI 根据目标 Java 类的结构生成 JSON Schema
2. 将 Schema 作为 `response_format` 参数发送给大模型
3. 大模型返回符合 Schema 约束的 JSON
4. Spring AI 自动反序列化为 Java 对象

## 接口说明

### 1. 输出为 POJO `GET /structured/actor`

让 AI 返回一个结构化的演员信息对象。

```
GET /structured/actor?name=周星驰
```

定义 Java 类：
```java
public class ActorFilms {
    private String actor;        // 演员姓名
    private List<String> movies; // 参演电影列表
    private String biography;    // 生平简介
}
```

调用代码：
```java
ActorFilms result = chatClient.prompt()
    .user("请告诉我关于演员 " + name + " 的信息...")
    .call()
    .entity(ActorFilms.class);  // 关键：指定输出类型
```

返回结果示例：
```json
{
  "actor": "周星驰",
  "movies": ["功夫", "大话西游", "少林足球"],
  "biography": "香港著名喜剧演员、导演..."
}
```

### 2. 输出为 List `GET /structured/list`

让 AI 返回一个字符串列表。

```
GET /structured/list?topic=Java学习路线
```

```java
List<String> items = chatClient.prompt()
    .user("请列出关于「" + topic + "」的5个要点...")
    .call()
    .entity(new ParameterizedTypeReference<List<String>>() {});
```

### 3. 输出为 Map `GET /structured/map`

让 AI 返回键值对结构的数据。

```
GET /structured/map?question=Java和Python的对比
```

### 4. 信息抽取 `GET /structured/extract`

从非结构化文本中提取结构化信息，这是最实用的场景。

```
GET /structured/extract?text=张三今年25岁，在北京工作，是一名软件工程师
```

返回：
```json
{
  "name": "张三",
  "age": "25",
  "city": "北京",
  "occupation": "软件工程师"
}
```

## entity() 方法说明

`entity()` 是结构化输出的核心方法，支持多种类型：

| 用法 | 说明 |
|------|------|
| `.entity(ActorFilms.class)` | 转为普通 POJO |
| `.entity(new ParameterizedTypeReference<List<String>>() {})` | 转为 List |
| `.entity(new ParameterizedTypeReference<Map<String, Object>>() {})` | 转为 Map |

## 应用场景

| 场景 | 说明 |
|------|------|
| **信息抽取** | 从简历、合同等文本中提取结构化字段 |
| **意图识别** | 将用户输入解析为 {intent, params} 结构 |
| **数据生成** | 让 AI 生成符合 schema 的测试数据 |
| **分类标注** | 将文本分类为预定义的标签结构 |
| **流水线** | AI 输出直接进入下游业务逻辑处理 |

## 注意事项

1. POJO 类需要有**无参构造器**和 **getter/setter**（反序列化需要）
2. 字段名会自动映射为 JSON 的 key，建议使用清晰的命名
3. 并非所有模型都支持 JSON Schema 约束，OpenAI GPT-4o 系列支持较好
4. 如果 AI 返回的内容不符合 Schema，可能会抛出解析异常

## 学习要点

1. `.entity(Class)` 是结构化输出的核心入口
2. 支持泛型类型，使用 `ParameterizedTypeReference`
3. Java 类的结构就是 AI 输出的约束
4. 信息抽取是最实用的应用场景
