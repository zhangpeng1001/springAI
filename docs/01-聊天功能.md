# 01 - 聊天功能（Chat）

> 对应代码：`ChatController.java`

## 功能说明

聊天是 Spring AI 最基础的功能。本模块演示了三种调用大模型的方式，从简单到灵活：

1. **ChatClient（推荐）**：Spring AI 提供的高级 API，链式调用，功能丰富
2. **ChatModel（底层）**：直接操作 Prompt，更细粒度的控制
3. **运行时参数覆盖**：在单次请求中动态调整 temperature 等参数

## 核心概念

### ChatClient vs ChatModel

```
┌─────────────────────────────────────┐
│           ChatClient（高级）          │  ← 推荐使用，支持链式API、流式、工具、记忆等
│  ┌───────────────────────────────┐  │
│  │      ChatModel（底层）          │  │  ← 直接操作 Prompt 和 ChatResponse
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

- **ChatClient** 封装了 ChatModel，提供更友好的 API
- **ChatModel** 是模型层的抽象，每种模型提供商都有对应实现（如 OpenAiChatModel）

### 基本调用流程

```
用户输入 → ChatClient.prompt().user(msg).call().content() → AI回复
```

## 接口说明

### 1. 简单对话 `GET /chat/simple`

最基本的聊天调用。

```
GET /chat/simple?message=你好
```

代码核心：
```java
String response = chatClient.prompt()
        .user(message)   // 设置用户消息
        .call()          // 同步调用
        .content();      // 获取文本内容
```

### 2. 获取完整响应 `GET /chat/detail`

获取包含 token 使用统计的完整响应。

```
GET /chat/detail?message=讲个笑话
```

返回内容包括回复内容和 token 使用量（输入/输出/总计）。

### 3. 使用底层 ChatModel `GET /chat/model`

直接使用 ChatModel 和 Prompt 对象。

```
GET /chat/model?message=什么是Spring AI
```

### 4. 运行时参数覆盖 `GET /chat/creative`

在单次请求中动态调整参数（如调高 temperature 增加创造力）。

```
GET /chat/creative?message=写一首关于春天的四行诗
```

代码核心：
```java
chatClient.prompt()
    .user(message)
    .options(OpenAiChatOptions.builder()
            .temperature(1.2)  // 覆盖为高温度
            .build())
    .call()
    .content();
```

## 关键参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| `temperature` | 生成温度，0~2，越高越发散 | 事实问答用 0.2，创意写作用 0.8~1.2 |
| `maxTokens` | 最大输出 token 数 | 根据需求设置 |
| `model` | 模型名称 | gpt-4o-mini（经济）、gpt-4o（强大） |

## ChatResponse 结构

```json
{
  "result": {
    "output": {
      "text": "AI回复的文本内容"
    }
  },
  "metadata": {
    "usage": {
      "promptTokens": 50,      // 输入token数
      "completionTokens": 100,  // 输出token数
      "totalTokens": 150        // 总token数
    }
  }
}
```

## 学习要点

1. ChatClient 是 Spring AI 推荐的入口，优先使用它
2. `.call()` 是同步调用，`.stream()` 是流式调用（逐字返回）
3. `.content()` 直接获取文本，`.chatResponse()` 获取完整响应对象
4. 运行时参数覆盖不影响全局配置，适合按场景调整
