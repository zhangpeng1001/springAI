# 02 - 提示词模板（Prompt Template）

> 对应代码：`PromptController.java`，模板文件：`resources/prompts/`

## 功能说明

提示词模板（PromptTemplate）类似于模板引擎（如 Thymeleaf、FreeMarker），
可以将变量动态填充到提示词中，实现提示词的**复用**和**管理**。

Spring AI 使用 StringTemplate 语法，变量用 `{变量名}` 表示。

## 为什么需要提示词模板

### 不使用模板（硬编码）

```java
// 每次都要拼接字符串，难以维护
String prompt = "请将以下文本翻译成中文：" + text;
```

### 使用模板（推荐）

```java
// 模板定义一次，变量动态填充
PromptTemplate template = new PromptTemplate("请将以下文本翻译成{lang}：{text}");
Prompt prompt = template.create(Map.of("lang", "中文", "text", text));
```

## 接口说明

### 1. 内联模板 `GET /prompt/inline`

直接在代码中定义模板字符串。

```
GET /prompt/inline?topic=面向对象编程&language=Python
```

代码核心：
```java
PromptTemplate promptTemplate = new PromptTemplate(
    "请简要对比 {topic} 在 Java 和 {language} 中的实现差异。"
);
Prompt prompt = promptTemplate.create(Map.of(
    "topic", topic,
    "language", language
));
```

### 2. 外部模板文件 `GET /prompt/external`

从 `resources/prompts/translate.st` 文件加载模板。

```
GET /prompt/external?text=Hello World&targetLang=日语
```

模板文件 `translate.st` 内容：
```
请将以下文本翻译成{targetLang}：
原文：{text}
...
```

代码核心：
```java
@Value("classpath:/prompts/translate.st")
private Resource translatePromptResource;

PromptTemplate promptTemplate = new PromptTemplate(translatePromptResource);
```

**外部文件的优势**：
- 提示词与代码分离，便于迭代
- 非开发人员可维护
- 支持版本控制和 A/B 测试

### 3. 系统提示词 `GET /prompt/system`

通过 `.system()` 方法设置 AI 的角色和行为。

```
GET /prompt/system?question=如何学习编程
```

代码核心：
```java
chatClient.prompt()
    .system("你是一位有10年经验的编程导师...")  // 系统提示词
    .user(question)                              // 用户问题
    .call()
    .content();
```

## 系统提示词 vs 用户提示词

| 类型 | 作用 | 设置方式 |
|------|------|---------|
| 系统提示词 | 定义 AI 的角色、行为准则、限制 | `.system()` 或 `defaultSystem()` |
| 用户提示词 | 用户的具体问题或请求 | `.user()` |

系统提示词在对话中"权重"更高，用于约束 AI 的整体行为。

## 模板文件格式

模板文件使用 `.st` 后缀（StringTemplate），语法：

```
你好，{name}！

你的订单 #{orderId} 已确认。
配送地址：{address}
```

## 配置中的默认系统提示词

在 `AiConfig.java` 中通过 `defaultSystem()` 设置了全局默认系统提示词：

```java
@Bean
public ChatClient.Builder chatClientBuilder(ChatClient.Builder builder) {
    return builder.defaultSystem("你是一个友好的中文AI学习助手...");
}
```

这样所有 ChatClient 请求都会自动带上这个默认角色设定。

## 学习要点

1. PromptTemplate 使用 `{变量名}` 语法，通过 `Map` 传参
2. 提示词可放在 `.st` 文件中，用 `@Value("classpath:...")` 加载
3. 系统提示词定义 AI 角色，用户提示词是具体问题
4. `defaultSystem()` 设置全局默认，`.system()` 覆盖单次请求
